# Cardano Island — Time Axis Implementation Plan

> Executed inline (superpowers:executing-plans) at the user's request ("don't come back, just build"). Each task is test-first. Code is written in the session against these interfaces.

**Goal:** monthly timeline (2021-09 → now) driving ships, settlers, road wear and building lifecycle from on-chain transactions and GitHub commits.

**Spec:** `docs/superpowers/specs/2026-10-20-time-axis-design.md`

## Global Constraints
- Months are `YYYY-MM` strings; the first month is `2021-09`; the last is the month of `generatedAt`.
- Flow weight `log10(1 + tx)`; dated presence and fallback flow = 10 tx/month.
- Decay thresholds: burning ≥ 4, ruin ≥ 6, grass ≥ 12 inactive months; at-risk when used and ≥ 6 months without commits (repo only).
- Same inputs → identical `world.json`. Time-dependent rendering is a pure function of `T`.
- Collected activity is committed under `data/activity/`; the build never touches the network.

## Review Focus
1. A product with a repo but no commits in the window (dormant library used by everything) → at-risk, never burning while traffic flows.
2. An entity with no activity data at all → stays standing ("no activity data"), never ruined.
3. A ship whose transactions stop then resume → away, then docked again; ended customers become wrecks, not ghosts.
4. Missing or malformed activity file → clear `data/activity/...: problem` error, not a crash.
5. Current month with partial data (month in progress) → not treated as an inactivity month by itself.

## Tasks

### Task 1: Schema + activity loading
- `NodeSchema`/`CustomerSchema` gain optional `onchain` `{scripts?: hex56[], metadataLabels?: int[], addresses?: string[], source?: url, note?: string}` and `active` `{from: YYYY-MM, until?: YYYY-MM}`.
- `pipeline/activity.ts`: `loadActivity(dir): { activity: Activity; errors: string[] }` where `Activity = { tx: Map<id, MonthCounts>; commits: Map<id, MonthCounts> }`, `MonthCounts = Record<string, number>`; validates file shape (zod) and that the file name equals `id`; unknown ids → error in validation.
- Loader: `activity` is an allowed entry in the data root.
- Tests: schema accepts and rejects; activity parse errors; ids must exist.

### Task 2: Month utilities (`pipeline/months.ts`)
- `monthRange(from, to): string[]`, `monthOf(isoDate): string`, `monthDiff(a, b): number`.
- Tests: ranges across years, diff sign, single month.

### Task 3: Timeline engine (`pipeline/timeline.ts`)
- `computeTimeline(graph, activity, months): Timeline` with the shape of spec §4.1.
- Helpers (exported, tested): `customerFlow(...)`, `nodeStates(...)`, `shipStates(...)`.
- Tests: flow rules 1–4 and ended; weights; per-month traffic equals `computeTraffic` with weights; states at 3/4/5/6/11/12 inactive months; recovery; at-risk; no repo; no data; construction in the founding month; the in-progress current month does not count as inactive; tiers per month; ship d/a/w transitions.

### Task 4: Pipeline integration
- `runPipeline` loads activity, derives months from `generatedAt`, emits `world.timeline`; existing fields are unchanged.
- `serializeWorld` stays compact. Fixture: `fixtures/mini/activity/...` for a few entities.
- Tests: fixture timeline fields and determinism.

### Task 5: Collector (`scripts/collect-activity.ts`, `scripts/lib/activity-sources.ts`)
- Pure: `txQuery(ids)` SQL builders for scripts, labels and addresses; `parseSqlRows(text)`; `commitsQuery(owner, repo, months)` GraphQL with aliased `history(since, until)`; `parseCommits(json, months)`.
- IO: MCP JSON-RPC call (`tools/call` → `analytics-execute-sql`), GitHub GraphQL via `GITHUB_TOKEN` or `gh auth token`; writes `data/activity/{tx,commits}/<id>.json`; `--only <id>`; polite concurrency.
- Weekly workflow refreshes activity and opens a pull request.
- Tests: query builders and parsers.

### Task 6: App time logic (`app/logic/time.ts`, `app/logic/routes.ts`)
- `monthAt(timeline, T) → { index, frac, month }`, `nodeStateAt`, `shipPhase(customer, T) → { docked: 0..1, state }`, `edgeTrafficAt(T)`, `tileTrafficAt(T)`.
- `settlerRoutes(world, idx, customerId)`: deterministic list of tile paths from harbor through product chains (heaviest dependency at each step) to the core district, then the trail to the mountain peak.
- `settlerPosition(route, i, n, T, seconds)`: pure.
- Tests: interpolation, phase transitions, route endpoints (starts at the harbor, ends at the peak), determinism.

### Task 7: Renderer and UI
- Timeline bar (slider, play/pause, speed, Now, sparkline, month label, keyboard).
- Building state layers: plot outline, scaffolding, flames and smoke, cracks; tier scale per month.
- Roads per `T`; ships leave and return; settler chain flow with a sparkle at the mark; panel sparklines and state sentence; lenses at `T`.
- e2e: slider to a past month changes the label and the panel state.

### Task 8: Data, collection run, review, publish
- Merge research identifiers and dates into YAML; run the collector; build; final whole-branch review; fix pass; republish the artifact.
